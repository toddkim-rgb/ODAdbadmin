# 국제개발협력센터 사업DB 관리시스템 — 프로토타입

제안요청서(해외건설협회 공고 제2026-21호)의 **사업DB 관리자 기능(SFR-016 ~ SFR-049)** 을 클릭해 볼 수 있는 화면 프로토타입입니다.
제안 때 사용한 **'사업 전 주기 로드맵' 시안**의 단계 구분·주체·규칙·화면을 반영했습니다.
서버 없이 브라우저만으로 동작하며, 입력·결재한 내용은 브라우저 저장소(localStorage)에 보관됩니다.
글꼴(Pretendard)·차트 라이브러리·세계지도를 모두 폴더 안에 포함해 **인터넷이 없는 시연장에서도 똑같이 보입니다.**

## 실행

- **온라인 시연: https://odadbadmin.vercel.app** (GitHub `main`에 올리면 Vercel이 자동으로 다시 배포합니다)
- `index.html`을 Chrome·Edge·Whale에서 바로 열면 됩니다.
- 또는 상위 폴더에서 로컬 서버로 실행합니다.

```bash
python -m http.server 5180 --directory prototype
```

- 좌측 하단 **데모 데이터 초기화**를 누르면 처음 상태로 돌아갑니다.
- 상단 **사용자 전환(데모)** 으로 역할을 바꾸면 메뉴·버튼·조회 범위가 권한에 따라 달라집니다.

| 시연 계정 | 역할 | 확인 포인트 |
|---|---|---|
| 최유진 선임 (사업1팀) | 사업담당자 | 본인 담당 사업만 조회, 등록·수정은 결재 상신, 외부 결정 기록 |
| 이서연 팀장 (사업1팀) | 부서장(결재권자) | 결재 대기 3건 (기간 연장 · 예산변경 · 재제안) |
| 김지훈 센터장 | 부서장(최종 결재) | 최종 승인 시 사업정보 자동 반영 |
| 서지민 차장 (정보화지원실) | 조회전용 | 등록·수정 버튼 미노출, 결재·관리 메뉴 차단 |
| 박준서 과장 (정보화지원실) | 시스템관리자 | 사용자·권한·코드·로그·알림·오픈 API·홈페이지 관리자 |

## 데이터

- **공개 사업DB 119건**: 사업명·국가·분야·유형·시작·종료연도·계약금액·시행계획 예산은 원천자료 그대로입니다. 공개 자료에 없는 발굴·예비·확정 일자는 규정(N-2·N-1)으로 계산해 **'계산 값'** 으로 표시합니다.
- **공모·심의 시나리오 37건** (로드맵 시안 예시 수치와 동일): 2026년 공모(2028년 시행) 24건 — 선정 9 · 고도화 보류 2 · 위원회 미선정 3 · 서류심사 미선정 10, 2025년 공모(2027년 시행) 상정 12건 — 의결 9 · 보류 3, 2025년 공모 미선정 1건.
- **추적조사**: 성과관리 지침 제26조 규칙(종료 후 매년 2월, 프로젝트 5년·연수 1년·그 외 3년, 2023년 이후 종료분)으로 생성. ’27.2 보고 대상 32건은 로드맵과 같습니다.
- 계약·집행·결재·일정·문서·PDM·평가·로그는 시연용 생성 데이터이고, 인물·기관·업체명은 모두 가상입니다.

## 로드맵 시안 반영 내용

| 로드맵 시안 | 프로토타입 위치 |
|---|---|
| 전 주기 로드맵 (연도 축 간트, 단계 칩, ’27.2 추적 보고 대상, 상세 패널 ①~⑤) | 사업관리 › 전 주기 로드맵 |
| 사업 전 주기 10단계와 단계별 주체 (주관 · 작성 · 결정 · 근거 지침) | 로드맵 상세 패널, 사업 상세 › 추진경과·일정 |
| 연도별 추진현황판 (시행연도 × 단계) | 사업관리 › 연도별 추진현황판 (단계별 보드 겸용) |
| 공모·미선정 관리 (퍼널, 사유, 같은 사업ID 차수, 차수 간 비교) | 사업관리 › 공모·미선정 관리, 사업 상세 › 기본정보 › 제안 차수 이력 |
| 발굴 정보 등록 (접수 시 사업ID 부여·변경 불가, 재제안이면 기존 사업ID) | 사업 등록 (발굴) |
| ♥ 외부 결정(위원회·국토부) 결과 기록 — 결재 없이 근거만 | 사업 상세 › 외부 결정 기록 |
| ♥ 확정되지 않은 변경 분리 표시 | 사업 상세 › 변경이력 |
| ♥ 지침 기한 규칙으로 예정일 자동 제안 | 사업 상세 › 추진경과·일정 › 지침 기한 자동 제안 |
| ♥ 2월 추적조사 제출 현황 · D-day | 전 주기 현황판, 성과 환류 |
| PDM 5단 × 4열 · 버전(제안→수정→확정→종료) · ♥ 조사보고서 누락 경고 · ♥ 지표 라이브러리 | 사업 상세 › 성과관리 |
| 추적조사 표준 항목 9개 × 차수, ♥ 후속 수주·연계 성과 | 사업 상세 › 성과관리, 성과 환류 |
| 성과 환류 (시행기관별 비교, 평가환류과제, 후속·연계 발굴) | 성과·통계 › 성과 환류 |
| 시스템관리 — 알림·팝업, 오픈 API | 시스템관리 › 알림·팝업, 오픈 API |
| 홈페이지 관리자 (사업DB 연계·대사, 공개 지정, 게시물↔사업ID, 배너·팝업·게시판·메뉴) | 홈페이지 관리 › 홈페이지 관리자 |
| 요구사항 중요도 · 단계 × 요구사항 매칭 · 단계별 주체 표 | 전 주기 로드맵 하단 (펼치기) |

결정 사항: 재제안은 **같은 사업ID의 다음 차수**, 외부 결정은 **결재 없이 근거 기록**, 결재선은 제안요청서 문구대로 **실무자 → 팀장 → 센터장**.

## 시연 시나리오 (약 15분)

1. **최유진** 전 주기 현황판 → KPI · 단계별 현황(세부상태) · ’27.2 추적조사 보고 D-day
2. 전 주기 로드맵 → 칩으로 '’27.2 추적 보고 대상' 필터 → 행 클릭 → 상세 패널(10단계 주체·②~⑤)
3. 연도별 추진현황판 → 2028·2027년 시행 발굴·예비 칸 → 공모·미선정 관리로 이동
4. 공모·미선정 관리 → 2026년 공모 퍼널(접수 24 → 선정 9) → `P2025-003 · 2차` 선택 → 1차 대비 변경 비교
5. `P2025-007` (예비 · 의결) → **외부 결정 기록** → 신규사업 확정 (결재 없이 반영) → 입찰·계약 탭 → 입찰·낙찰 결과 등록 (결재 상신)
6. **이서연 팀장** → 결재함 → `P2026-004` 재제안(2차) 승인 → **김지훈 센터장** 최종 승인 → 같은 사업ID 2차로 접수 확인
7. `P2026-112` → 변경이력 탭 → 확정 이력과 '확정되지 않은 변경' 분리 표시 확인
8. (센터장 계정 그대로) 추적조사 사업 `P2023-084` → 성과관리 탭 → PDM 버전 · 추적조사 미제출 → 성과 환류 화면
9. 통계 현황 · 피봇 분석
10. **박준서 과장** → 홈페이지 관리자(공개 지정 → 불일치 → 홈페이지에 반영) · 오픈 API 호출 · 알림·팝업

## 프로토타입 범위 밖

- 공개 홈페이지 화면(SFR-008~014의 사용자 화면), 로그인·인증 화면(SFR-005)
- 실제 파일 저장·다운로드, HWP 변환, ZIP 일괄 다운로드 (버튼은 있으나 안내 메시지로 대체)
- 엑셀은 CSV(UTF-8)로 내려받습니다. 본 구축 시 피봇·그리드·엑셀은 상용 그리드 솔루션으로 대체할 수 있습니다.
- 지침 기한 13개 중 로드맵에 명시된 기한만 규칙화했습니다. 나머지는 착수 시 센터와 기한표를 확정합니다.
